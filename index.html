Simply Private

Your memories, encrypted.
Your device, in control.

Photok gives you a private space for photos and videos. Imported media is protected with AES-256 encryption and only decrypted in memory while you use the app. Photok does not upload your media to a cloud service.

Open Source & Privacy-First

Nothing to hide?
Everything to protect.

Photok is built with a privacy-first philosophy. No account, no cloud upload, no ads. It uses privacy-friendly analytics to improve stability and user experience; these are never used for advertising or cross-app tracking. The core app source code is public so you can verify how it works.

  • No account required — open the app and go.
  • No cloud upload — Photok does not upload your media.
  • No advertising — analytics are used only to improve the app.
  • Open-source core — Apache 2.0. Read the code, fork it, contribute.
  • Community translated — available in 13 languages.
